# SweProtein

Demosajt för ett påhittat proteinshake-märke. Next.js 16, SV/EN, scrollstyrd scen.

```
npm install
npm run dev
```

- Texter, smaker och inställningar: `src/lib/content.ts`
- Scrollscenen: `src/components/Scene.tsx` (ritas i kod tills H3-filmen finns)
- H3-film till scenen: se `h3/README.md`

Demosajt byggd av SweGBG Agency.
